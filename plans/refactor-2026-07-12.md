## Architecture overview

Bash multi-model orchestrator driven from Claude Code slash commands. No daemon, no DB, no MCP.

- **Languages:** Bash ≥5.1 (~2,300 lines), Node ESM (site/server.mjs, 329 lines), static HTML/CSS/JS (site/).
- **Core modules:**
  - `src/swarm-lib.sh` (843) — bus primitives: init, conf precedence, atomic claim (rename-to-unique-dest), heartbeat/reap, gate math, limit flags, per-lane invocation builder (`lane_cmd`, `env -i` containment), answer extraction, limit-signature detection, EXEC_CHAIN position tracking, verify-wave spec writer, run-evidence ledger, web-cockpit ensure/open.
  - `swarm-run.sh` (480) — `/swarm` driver: enqueue, `wait -n -p` FANOUT-bounded pool, FR-12 watchdog, FR-13 driver-death sweep, FR-14 inode fencing tokens, finalize (done marker + provenance + ledger), verify subcommand, config subcommand.
  - `swarm-loop.sh` (504) — `/swarm-loop`: criteria.md contract (checksum-guarded), scratch git worktree, iterate (exec→oracle→judge), stop rules (goal/plateau/oscillation/max-iter/budget/wall-clock/human-abort), HALTED/COMPLETE artifacts.
  - `src/swarm-ctl` (123) — bus control verbs: pause/resume/cancel/add/abort/status/kill.
  - `swarm-mon.sh` (204) — read-only tmux cockpit (BOARD/FIREHOSE/COST/CONTROL).
  - `site/server.mjs` (329) + `site/*.html` — Ground Control web cockpit on :4747 + overview site (also deployed as Cloudflare Worker at unimatrix.asajj.cz).
- **External integrations:** headless CLIs `claude -p`, `codex exec`, `gemini -p`, GLM via z.ai child-env swap on `claude -p`. Secrets grepped per-key from `$ENV_MASTER_FILE` (never sourced).
- **Data flow:** Fable writes `.bus/specs/<id>.prompt` (+ optional `.lane`/`.write` sidecars) → enqueue → pool claims (atomic `mv` to `claimed/<id>.<lane:model>`) → worker `tee`s stream-json to `run-<id>.jsonl` → `extract_answer` normalizes to `res-<id>.txt` → done marker with served-lane provenance → optional cross-model verify wave (`v-<id>` pinned to VERIFY_MAP lane).
- **Auth model:** per-lane scratch HOME under the bus; claude/codex get one credential file copied fresh per spawn; gemini/glm are pure env-token.
- **No database, no CI config in-repo** (no .github/workflows), no deploy pipeline beyond `site/` wrangler.
